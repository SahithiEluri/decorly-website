# Decorly — event decorator research website

**Beautiful events. Better organized.**

A responsive, static concept website for Decorly, a proposed event-decorator workflow platform. Decorly is **in development**. Optional AI-assisted decor concepts and other features shown are **planned**, not live. All three event-scene images are AI-generated.

## Preview locally
Open `index.html` in a browser. `styles.css`, `script.js`, and `assets/` must remain alongside it. No install or build required.

## Publish on GitHub Pages
1. Create a new GitHub repository (for example `decorly-website`).
2. Upload **the contents of this folder** to the repository root, including `index.html` and `assets/`.
3. In GitHub, open **Settings → Pages → Build and deployment**, select **Deploy from a branch**, then `main` and `/(root)`. Save.
4. Wait for GitHub to provide a public site URL; open it and test desktop, mobile, and the feedback buttons.

**Note:** GitHub Pages is publicly accessible. Do not commit private decorator responses, credentials, or personal contact details. The Google Sheet should stay private.
